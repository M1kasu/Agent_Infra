## 单个 Agent 定义模板（每个 Agent 复制一份）

### Agent X ·（名称）

- **一句话职责**：
- **输入**：收到什么（来自谁）
- **输出**：产出什么（给谁、什么格式）
- **需要的能力**：（→ 挂到 [06 Skill 清单](06-skill-catalog.md)）
- **不负责什么**：（边界，防止职责蔓延）
- **为什么必须是独立 Agent**：（合并进其他 Agent 会损失什么）
- **失败时的行为**：重试 / 上报 / 降级

## 常见拆分理由参考

- 上下文隔离：诊断需要全量日志，执行只需要精确指令，混在一个上下文里互相污染
- 工具权限不同：执行类 Agent 才持有写权限，且必须经过审批（→09）
- 迭代节奏不同：分析逻辑频繁变，执行逻辑要求稳定
