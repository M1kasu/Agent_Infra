# 作品简介

项目名称：OfficeOps Agent

企业 SaaS 访问故障常需 IT 人员跨 IAM、VPN、权限和服务后台排查、修复与确认。OfficeOps 以 AgentTeams Manager–Workers 为基点，由 Manager 编排上下文、诊断、修复验证三类 Worker：采集多源状态、诊断根因、按风险调用工具，再重读状态验证访问。Demo 处理 Alice 的 Docs 故障：确认服务、VPN、权限正常且账号锁定后自动解锁；若工具伪报成功，复验发现仍锁定，系统重试后失败关闭，落实“Tool Success ≠ Task Success”。创新与差异在于多源诊断、执行—观察—验证闭环和可复用 Skill/Tool 分层，而非关键词脚本。已完成官方 AgentTeams v1.2.2 Manager、3 Worker、Matrix、Skills 与角色隔离 MCP 的真实闭环，并具备 Sandbox、Trace、Fake Success 和 13 项测试。项目采用 Apache-2.0，可复用于 Wiki、Jira、GitLab、CRM、OA、SSO 和 VPN。
